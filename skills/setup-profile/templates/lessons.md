# Lessons

Dated, generalised rules appended by the debrief skill after each interview, rejection, or recruiter comment. Every prep reads this file and turns the most recent and most repeated lessons into "patterns to land in every answer".

Format for each entry:

## YYYY-MM-DD | <short rule title>
**Rule:** <one or two sentences, written as an instruction for next time>
**Why:** <what happened, which company and stage, without blame>
**How to apply:** <where it shows up: CV, recruiter screen, panel, case study, questions for them>
**Evidence:** <the candidate's stories that already support the new behaviour>
